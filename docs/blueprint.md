# **App Name**: Rutin Tracker

## Core Features:

- Expense Item List: Display a list of routine expenses that remain consistent each month, based on data provided.
- Add/Remove Expenses: Allow users to add or remove expenses from the routine list. Expenses deleted this month, will reappear again the next month.
- Monthly Reset: Automatically reset the expense list at the start of each month.
- Expense Checkbox: Provide a checkbox next to each expense to mark it as completed or not.

## Style Guidelines:

- Primary color: Soft teal (#74B49B) to represent balance and consistency.
- Background color: Very light grayish-green (#F0F4F2).
- Accent color: Muted orange (#C48A5B) for highlighting important actions.
- Body and headline font: 'PT Sans', a sans-serif font providing modern legibility and a touch of warmth, used for both headlines and body.
- Use simple and intuitive icons for expense categories and actions.
- Clean and straightforward layout for easy expense tracking.
- Subtle animations when checking expenses as completed.
